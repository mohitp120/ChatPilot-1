# ChatPilot AI — Native Android Project

Your AI copilot for every conversation.

## Tech Stack
- Kotlin 1.9+
- Jetpack Compose & Material 3
- Android AccessibilityService
- WindowManager Overlay (TYPE_APPLICATION_OVERLAY)
- Coroutines & Flow
- OkHttp / Retrofit for secure HTTPS backend
- Clean Architecture & Modular Adapter Pattern

## Setup & Running in Android Studio
1. Open this folder in Android Studio Hedgehog (or newer).
2. Sync Gradle files.
3. Run on an Android device or emulator running Android 8.0 (API 26) or higher.
4. On first launch, follow the onboarding flow to enable:
   - System Alert Window permission (Display over other apps)
   - AccessibilityService permission (Settings > Accessibility > ChatPilot AI)
5. Open WhatsApp, Instagram, Telegram, or LinkedIn.
6. The ChatPilot floating bubble will appear above your chat!
